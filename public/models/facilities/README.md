# 3D 시설물 모델 라이브러리 (`public/models/facilities/`)

이 디렉터리는 'GeoBrief 3D'의 강원권 군 유휴지 거점 및 전술 시설물 배치에 사용되는 3D 모델(GLB/glTF) 에셋 공간입니다.

## 파일 명명 규칙
- **표준 병영 막사/지휘소**: `barracks_hq.glb` (또는 `.gltf`)
- **복합 국방 R&D 타워/연구동**: `defense_rd_tower.glb` (또는 `.gltf`)
- **군수 물류 데포**: `logistics_depot.glb` (또는 `.gltf`)
- **경계·감시 철골 타워**: `watch_tower.glb` (또는 `.gltf`)
- **표준 헬리패드(H) 베이스**: `helipad_base.glb` (또는 `.gltf`)

## 렌더링 파이프라인
1. 사용자가 해당 시설물을 배치하거나 강원권 거점(원주 캠프롱, 춘천 102보충대, 철원 보병연대 등)을 선택하면, 시스템은 우선 이 디렉터리의 GLB 파일을 비동기 조회합니다.
2. GLB 파일이 아직 존재하지 않는 경우, **Three.js 절차적 복합 메쉬(Procedural Composite Mesh - 박공 경사 지붕, 창문 돌출 프레임, 트러스 아치, 격자 철골 기둥, 옥상 헬리패드 등)** 엔진이 즉시 작동하여 고품질 3D 메쉬로 완벽히 폴백 렌더링됩니다.
3. 상단 툴바의 **[3D 디테일: 일반(LOD1) / 실감(LOD2+)]** 토글을 통해 프레임 속도와 시각적 품질을 실시간으로 전환할 수 있습니다.
